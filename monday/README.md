# Datos de Monday (Kelly Trader)

- `crudo/`: lectura de Monday tal cual, sin modificar.
- `generar.py`: genera `../monday.js` y revisa los datos.

```bash
python monday/generar.py
```

- `../verificar.html`: compara Monday con lo que muestra el dashboard.

El detalle de columnas está en [../MAPEO-MONDAY.md](../MAPEO-MONDAY.md).
